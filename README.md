# Meme Deck

Личная дека мемов для телефона. Сетка кнопок с превью: тап — мем на весь экран со звуком.
Все хранится только на телефоне (IndexedDB), сервер не нужен, работает без интернета.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | все приложение: верстка, стили, логика |
| `manifest.json` | чтобы ставилось на экран «Домой» как приложение |
| `sw.js` | service worker: кэширует приложение для офлайна |
| `icons/` | иконки (192, 512, maskable, apple-touch-icon) |

## Как пользоваться

- **+** внизу справа — выбрать видео / картинки / гифки (можно несколько сразу). Если открыта категория, новые мемы попадут в нее.
- **Тап** по кнопке — мем на весь экран. Закрыть: тап или свайп вниз. Кнопка «Повтор» — видео по кругу.
- **Долгий тап** — меню: переименовать, сменить категорию, сбросить счетчик, удалить.
- **Вкладки сверху**: «Все», «Частые» (по числу запусков), твои категории.
- **Кнопки внизу слева**: настройки, режим порядка (подержать мем и перетащить), поиск.
- **Настройки**: сколько места занято, повтор, управление категориями, бэкап в ZIP и импорт из ZIP.

## Деплой (бесплатно, с HTTPS)

HTTPS обязателен: без него не работает service worker и установка на экран «Домой».

### Вариант 1. GitHub Pages через сайт (без терминала)

1. Зайди на github.com → **New repository** → имя `meme-deck` → **Public** → Create.
2. На странице репозитория: **Add file → Upload files** → перетащи `index.html`, `manifest.json`, `sw.js` и папку `icons` → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/meme-deck/`.

### Вариант 2. GitHub Pages одной командой (с сервера, где залогинен `gh`)

```bash
cd /root/meme_deck && git init -q && git add -A && git commit -qm "Meme Deck" && gh repo create meme-deck --public --source=. --push && gh api -X POST repos/{owner}/meme-deck/pages -f "source[branch]=main" -f "source[path]=/"
```

Адрес тот же: `https://<логин>.github.io/meme-deck/`.

### Вариант 3. Cloudflare Pages (можно приватный репозиторий или вообще без GitHub)

1. dash.cloudflare.com → **Workers & Pages → Create → Pages → Upload assets**.
2. Имя проекта `meme-deck` → перетащи папку с файлами → **Deploy**.
3. Адрес: `https://meme-deck.pages.dev`.

### Обновление

Залей измененные файлы туда же. Приложение на телефоне подхватит новую версию со второго запуска (первый запуск берет из кэша, в фоне скачивает новую).

## Установка на телефон

**iPhone (только Safari):** открой адрес → кнопка **Поделиться** (квадрат со стрелкой) → **На экран «Домой»** → Добавить.

**Android (Chrome):** открой адрес → меню **⋮** → **Установить приложение** (или «Добавить на главный экран»).

Важно: мемы живут внутри установленного приложения. На iPhone данные Safari-вкладки и иконки на экране «Домой» — **разные хранилища**, поэтому добавляй мемы уже в установленном приложении.

## Особенности iPhone

- Видео играет внутри приложения (`playsinline`), звук включается, потому что старт идет прямо из тапа. Если iOS все же заблокирует звук, видео начнется без звука и появится кнопка «Включить звук».
- Звук идет даже при беззвучном режиме (переключатель сбоку) — это поведение видео в iOS.
- Место: iOS дает сайтам большую квоту (обычно десятки ГБ, зависит от свободного места), занятое видно в настройках.
- Если удалить иконку с экрана «Домой», мемы удалятся вместе с ней. Делай бэкап (Настройки → Экспорт в ZIP → «Сохранить в Файлы»).
- Экспорт собирает архив в памяти телефона: коллекция больше ~1 ГБ может не влезть.

## Особенности Android

- Видео `.mov` с iPhone (HEVC) может не играть в Chrome на Android — лучше mp4.
- HEIC-фото Chrome не открывает; такие файлы приложение пропустит и скажет об этом.
